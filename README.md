# Shelter Dog Adoption & Tracking System  
A Database Solution to Optimize Adoption Efficiency and Prevent Shelter Overcrowding

## Overview
This project addresses the growing challenge of shelter overcrowding by developing a centralized database system to manage dog intake, foster history, adopter matching, and shelter capacity. It is designed to automate operations, streamline adoption matching, and promote data-driven decision making in animal rescue and adoption organizations.

## Objectives
- Automate dog-adopter matching based on size, breed, and home environment
- Track shelter capacity and trigger alerts when occupancy exceeds 70%
- Centralize foster care, adoption records, and donor/volunteer engagement
- Generate real-time reports on adoption trends and shelter utilization
- Improve overall shelter efficiency and support community outreach

## Technologies Used
- Microsoft Access (for prototype development)
- SQL (queries and joins)
- Entity-Relationship Diagram (ERD)
- Relational Schema Design
- Macros for automation
- Form-based user interface for shelter staff

## System Features
- **Dog Registration Form:** Tracks individual dog information
- **Adopter Profile Form:** Captures preferences for better matching
- **Search & Match Form:** Automates ideal dog-adopter pairing
- **Overcapacity Alert:** Warns staff when space limits are exceeded
- **Report Automation:** Tracks adoption success rates and shelter performance

## Business Impact
- **Increased Adoption Success Rates:** Efficient and accurate dog-adopter matching
- **Reduced Shelter Overcrowding:** Real-time monitoring of space and foster placements
- **Improved Community Engagement:** Tools to track and manage volunteers and donations
- **Operational Efficiency:** Reduces manual tracking and administrative burden

## Future Enhancements
- AI-based adoption recommendation engine
- Online integration with pet adoption platforms
- Expanded tracking for medical history, behavior assessments, and post-adoption check-ins
